# Your Energy

Фінальний проєкт курсу GoIT Advanced JavaScript and TypeScript.

Fitness web app: фільтри вправ, пошук, модалка деталей, favorites
(localStorage), цитата дня та підписка на email.

## Live page

[https://dskintiian.github.io/goit-advancedjs-final/](https://dskintiian.github.io/goit-advancedjs-final/)

## Stack

- Vite
- TypeScript
- HTML / CSS
- modern-normalize
- DM Sans (`@fontsource/dm-sans`)

## API

Base URL: `https://your-energy.b.goit.study/api`

## Підготовка до роботи

1. Встанови залежності: `npm install`
2. Запусти розробку: `npm run dev`
3. Відкрий [http://localhost:5173/goit-advancedjs-final/](http://localhost:5173/goit-advancedjs-final/)

## Scripts
